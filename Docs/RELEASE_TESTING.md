# OmniVoice 0.0.1 — 内部测试说明

这是一个**未公证的 ad-hoc 签名测试版**，不是正式发布版。给信任的小范围测试者用，
不适合大规模分发——正式发布前需要 Developer ID 签名 + 公证（见
`Docs/PROGRESS.md` 的 Release pipeline 条目）。

## 安装

1. 拿到 `OmniVoice.app`（压缩包/AirDrop 都可以）后，先解压/拷贝到
   `/Applications` 或任意位置。
2. 因为没有公证，macOS 大概率会拒绝直接打开（提示"已损坏，无法打开"或"来自身份
   不明的开发者"）。打开终端，执行：

   ```bash
   xattr -cr /path/to/OmniVoice.app
   ```

   这会清除下载/传输时打上的隔离标记。之后正常双击打开即可（如果仍提示身份不明，
   右键点 App → 打开，再确认一次）。
3. 首次启动看不到 Dock 图标或窗口是正常的——这是纯菜单栏应用
   （`LSUIElement`），图标在屏幕右上角菜单栏里（一个波形图标）。

## 首次使用需要授权的权限

点击菜单栏图标 →"开始转录"后，系统会依次弹出权限请求：

- **麦克风** — 必须允许，否则完全无法录音。
- **语音识别** — 必须允许（用的是系统自带的 Speech 框架）。
- **屏幕录制**（仅当勾选了菜单栏的"包含系统声音"时才需要）——如果没有预先授权，
  会在状态栏看到红字提示"需要在系统设置里授权屏幕录制权限"。去
  系统设置 → 隐私与安全性 → 屏幕录制，勾选 OmniVoice，然后**重新启动 App**
  权限才会生效（macOS 的限制，不是 bug）。

## 已知范围（测试期间请知悉）

- 只有系统自带引擎（Speech / Translation）能用，模型引擎（R2T2/T3PO）还没接入，
  设置里对应的模型选择器是禁用状态。
- 界面只有中文，没有本地化。
- 没有自动更新机制——下一个测试版需要重新走一遍上面的安装步骤。
- 悬浮窗语言选择器目前是精选的常用语言列表（约 16 种），系统语音识别对其中
  俄语/阿拉伯语/越南语/泰语暂不支持作为源语言（已在 UI 里过滤掉，只影响能否
  选它们作为"源语言"，翻译目标语言不受影响）。

## 反馈问题时请提供

- 具体操作步骤 + 期望结果 + 实际结果。
- 如果是崩溃或卡死：`~/Library/Logs/DiagnosticReports/` 下对应时间的
  `OmniVoice-*.ips` 崩溃日志（如果有）。
- macOS 版本（`sw_vers`）。
