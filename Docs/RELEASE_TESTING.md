# OmniVoice 0.1.0 — 内部测试说明

这是一个**未公证的 ad-hoc 签名测试版**，不是正式发布版。给信任的小范围测试者用，
不适合大规模分发——正式发布前需要 Developer ID 签名 + 公证（见
`Docs/PROGRESS.md` 的 Release pipeline 条目）。

## 安装

1. 拿到 `OmniVoice.app`（压缩包/AirDrop 都可以）后，先解压/拷贝到
   `/Applications` 或任意位置。
2. 因为没有公证，macOS 大概率会拒绝直接打开（提示"已损坏，无法打开"或"来自身份
   不明的开发者"）。打开终端，执行：

   ```bash
   xattr -cr /path/to/OmniVoice.app
   ```

   这会清除下载/传输时打上的隔离标记。之后正常双击打开即可（如果仍提示身份不明，
   右键点 App → 打开，再确认一次）。
3. 首次启动看不到 Dock 图标或窗口是正常的——这是纯菜单栏应用
   （`LSUIElement`），图标在屏幕右上角菜单栏里（一个波形图标；有模型下载在
   进行时会临时变成下载进度百分比）。

## 首次使用需要授权的权限

点击菜单栏图标 →"开始转录"后，系统会依次弹出权限请求：

- **麦克风** — 必须允许，否则完全无法录音。
- **语音识别** — 仅使用系统自带引擎（Speech）时需要，必须允许。
- **屏幕录制**（仅当勾选了菜单栏的"包含系统声音"时才需要）——如果没有预先授权，
  会在悬浮窗状态栏看到红字提示"需要在系统设置里授权屏幕录制权限"。去
  系统设置 → 隐私与安全性 → 屏幕录制，勾选 OmniVoice，然后**重新启动 App**
  权限才会生效（macOS 的限制，不是 bug）。

## 本地模型引擎（R2T2 / T3PO）

这个版本开始，本地模型引擎（R2T2 识别、T3PO 翻译）也能用了，但**权重不随
App 打包**，需要手动下载：

1. 菜单栏图标 → "模型管理…"，为想用的引擎点击"下载"（R2T2 约 2.4GB，T3PO
   约 9.8GB，取决于网络可能要几分钟到几十分钟）。
2. 下载完成后，去"设置…"里把对应的"引擎"切换成本地模型（未下载的模型不会
   出现在选择器里；如果分类下完全没有下载任何本地模型，选择器下方会有文字
   提示去"模型管理…"下载）。
3. 下载/删除模型引擎的权重只能在"模型管理…"窗口里做，不会在点"开始转录"
   或"预加载模型"时自动触发下载——没下载就选了本地模型引擎，会自动回退用
   系统引擎，不会报错卡住。
4. 下载进度在关掉"模型管理…"窗口后也能看：菜单栏图标本身会变成进度百分比，
   菜单里的"模型管理…"这一行也会带进度。

## 悬浮窗

- 悬浮窗的位置/大小现在会记住——拖动/缩放过一次之后，下次启动会停在原地；
  全新安装（或从没调整过）默认停在屏幕底部居中（常见字幕位置）。
- "设置…"里新增"悬浮窗"分组，可以分别调节"背景透明度"和"内容透明度"
  （前者只影响悬浮窗背景的可见程度，后者影响文字和按钮，两者互不干扰）。

## 已知范围（测试期间请知悉）

- 界面只有中文，没有本地化。
- 没有自动更新机制——下一个测试版需要重新走一遍上面的安装步骤。
- 悬浮窗语言选择器目前是精选的常用语言列表（约 16 种），系统语音识别对其中
  俄语/阿拉伯语/越南语/泰语暂不支持作为源语言（已在 UI 里过滤掉，只影响能否
  选它们作为"源语言"，翻译目标语言不受影响）。
- 本地模型引擎目前每个只有一个量化版本可选（R2T2 Q8_0、T3PO Q5_K_M），没有
  多档位可切换。
- 崩溃/错误日志导出、隐私说明文案还没做（仍是占位状态）。
- 用 Homebrew 装的话，`brew tap hdcola/tap` 之后先执行一次
  `brew trust hdcola/tap` 再 `brew install --cask omnivoice`（新版
  Homebrew 7+ 要求先信任第三方 tap，否则会报"Refusing to load cask ...
  from untrusted tap"；只需做一次）。
